# Portfolio Website

### Built on React | Powered by Contentful Headless CMS

Vite + React app. Deployed on Netlify.

Website:

- https://saljuk.com
- https://saljuk.netlify.app/

## Local development

```bash
npm install
npm start
```

Contentful credentials live in `.env` as `REACT_APP_CONTENTFUL_SPACE_ID` and `REACT_APP_CONTENTFUL_ACCESS_KEY` (Vite `VITE_` equivalents are also supported).

## Scripts

- `npm start` / `npm run dev` — local dev server
- `npm run build` — production build to `build/`
- `npm run preview` — preview the production build
- `npm test` — run Vitest
